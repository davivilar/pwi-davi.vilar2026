Aula: Formulários HTML

Nesta aula vamos trabalhar com formulários HTML, elemento essencial para coleta de dados em páginas web.

💡 O formulário permite que o usuário envie dados para um sistema!

📋 Exemplo de Formulário

Observe o código abaixo:

<form>

    <!-- Campo texto -->
    Nome: <input type="text">

    <!-- Campo número -->
    Idade: <input type="number">

    <!-- Campo email -->
    Email: <input type="email">

    <!-- Botão envio -->
    <button>Enviar</button>

</form>

📌 Principais tipos de INPUT

  • text → texto simples
  • number → números
  • date → data
  • email → validação de email
  • password → senha
  • radio → escolha única
  • checkbox → múltiplas opções
  • color → seleção de cor
  • file → upload de arquivo

🎯 Desafios

🧩 Desafio 1 — Validação

  • Tornar obrigatórios: nome, email e telefone
  • Validar formato do email
  • Usar pattern no CEP

🧩 Desafio 2 — Organização

  • Utilizar fieldset e legend
  • Separar em: Dados pessoais, Endereço e Preferências

🧩 Desafio 3 — Lógica

  • Criar campo: "Possui CNH?"
  • Adicionar campo número da CNH

🧩 Desafio 4 — Estilo

  • Centralizar o formulário
  • Destacar campos obrigatórios
  • Melhorar botão com hover
